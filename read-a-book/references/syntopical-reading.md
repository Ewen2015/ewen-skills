# 主题阅读：五个步骤

主题阅读是最高层次、也最主动的阅读。**角色反转是关键：分析阅读里书是主人，主题阅读里你是主人，书为你服务。** 你的主题才是重点，不是你读的书。

## 准备

1. 先建书单：请教专家、翻参考书目、用主题工具书。
2. **对书单上的书先做检视阅读，再做分析阅读。** 用检视把书目筛到合理规模，同时建立对主题的清晰概念。跳过检视就想分析上百本书，行不通——那会花掉你十年。

## 五个步骤

1. **找到相关的章节。** 你要的不是理解整本书，而是找出这本书对你的问题有什么帮助。作者可能完全无意地解答了你的问题，这可能与他的写作目的相去甚远——无关紧要。
2. **带引作者与你达成共识。** 由**你**建立一套中立的词汇，让各位作者使用你的语言，而不是你跟着任何一位作者走。这本质上是一项翻译工作。照抄某位作者的术语，你很快会迷失，也无法理解其他作者。
3. **厘清问题。** 列出一组秩序清楚的问题，让所有作者来回答。作者可能对某个问题保持沉默；此时可以从他书中推出"若他考虑到，将会如何回答"，但必须克制——不能把话塞进作者嘴里。
4. **界定议题。** 把各作者对同一问题的不同回答整理出来，形成正反或多方的议题。当两个真正了解该问题的作者给出相反答案时，这才是"真正有参与的议题"。多数情况是：答案不同，源于对问题本身的认知不同。
5. **分析讨论。** 不只是排列答案，而是要说明不同答案及其理由，并说明你据以分类的根据。把争议的前后关系整理清楚——即使没有任何一位作者做过这件事。

前四步与分析阅读的前两组规则互相辉映；第五步则回答"这是真实的吗？这与我何干？"

## 客观的必要性

主题阅读追求"**辩证的客观**"：面面俱到，而自己不预设立场。

- 不能因为某个立场无人支持就认定它为假，也不能因为所有人都同意就认定它为真。
- 保持中立比面面俱到容易——但要小心偏见以微妙方式渗入：如何总结、强调什么、忽略什么。
- **主题阅读的目的不是给出最终答案**，而是对讨论本身作出清楚、公正的报告。一旦你主张某一种观点为真，你就不再是主题阅读者，而只是讨论中的又一个声音。

一个可操作的自检：写完报告后回头看，读者能否从你的文字里看出你本人站在哪一边？如果能，就还不够客观。
