# 斯堪的纳维亚风格

一套靠**留白、对齐、字体、比例、清晰度**承载设计的方法。这里没有 logo、没有插画、没有装饰件——
本 skill 不附带任何品牌资产，也不要往里塞第三方标识。

## 核心原则

**克制（restraint）是唯一的设计原则。** 其余规则都是它的推论。

产物应当传达：高级但不炫技 · 极简但不空洞 · 人性但不戏谑 · 技术但不冷漠 · 冷静、结构化、精确 · 自信但不张扬 · 编辑感而非装饰感。

**不做**：杂乱、装饰、视觉噪音、跟风的 UI 风格、通用企业模板、彩色 SaaS 美学、玻璃拟态、霓虹、重阴影、光泽、过度圆润的气泡组件。

判断标准很简单：**删掉它，信息是否变少？** 不会变少的东西，就删掉。

## 先判断产物类型

三类产物共用同一套设计语言，但落地方式不同：

| 产物 | 做法 |
| --- | --- |
| PPT / 幻灯片 | 按下面的版式网格定位，尺寸 33.867 × 19.05 cm（16:9 宽屏） |
| 单页 HTML / 报告页 | 用 [`assets/slide.html`](assets/slide.html) 起步，读 [`references/web-artifacts.md`](references/web-artifacts.md) |
| 数据密集页面 | 先读本页的可视化部分，再读 [`references/dataviz-guide.md`](references/dataviz-guide.md) |

## 版式网格

幻灯片 33.867 × 19.05 cm（16:9）。以下坐标是硬约束，不要凭感觉挪。

| 元素 | 位置 | 尺寸 | 说明 |
| --- | --- | --- | --- |
| 眉标 Kicker | 距左 0.99 cm，距顶 0.83 cm | 21.96 × 0.52 cm | 可选。位于上分割线**上方**，用于章节标签／分类／面包屑 |
| 上分割线 | 距顶 1.55 cm | 全出血，0.25pt | 在标题**上方** |
| 标题 | 距左 0.99 cm，距顶 2.03 cm | 母版基线 0.99×2.16 cm，尺寸 31.90×1.71 cm | 32pt，常规字重 |
| 内容区 | (0.99, 4.40) cm | 31.90 × 11.93 cm | 所有正文都在这里面 |
| 纵向分割线 | x = 21.05 cm，y 1.56 → 17.50 cm | 高 15.94 cm，0.25pt | 双栏布局才用 |
| 下分割线 | 距顶 17.50 cm | 全出血，0.25pt | 在页脚区域**上方** |
| 页脚 | 距顶 17.74 cm | 高 0.50 cm | 见下节 |

分割线规则（不可违反）：

- **全出血**：边到边，左右不留边距。
- **始终 0.25pt**，不得更粗。
- 颜色跟随文本色：亮色背景为黑，暗色背景为白。
- **禁止使用强调色**（蓝／橙）。

详细坐标、双栏与四类页面差异见 [`references/layout-grid.md`](references/layout-grid.md)。

## 字体与层级

字体栈优先用系统无衬线，需要辨识度时可换 `Inter` 或 `IBM Plex Sans`：

```css
--font-sans: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Helvetica, Arial,
             "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

中文排版把中文字体放在拉丁字体之后，让英文用系统无衬线、中文正确回退。

| 层级 | 字号 | 字重 |
| --- | --- | --- |
| 标题 | 32pt | 400（不要人为加粗） |
| 正文 lvl1 | 16pt | 400 |
| 正文 lvl2 | 14pt | 400 |
| 正文 lvl3 | 12pt | 400 |
| 正文 lvl4+ / 页脚 | 11pt / 9pt | 400 |

- 字重只在需要建立层级时用，**避免通篇加粗**；小标签用字距（`letter-spacing: .16em`）而不是加粗来区分。
- 层级靠**字号、间距、位置**建立，不靠颜色。
- 正文行宽控制在 65–75 字符；中文每行 30–40 字。
- 除链接外不用下划线；避免通篇大写。

## 页脚规范

内容页的页脚有四个元素，位置固定，**四个都必须有**。缺任何一个（尤其页码和居中文本）都是硬错误。

| 元素 | 位置 (X, Y) | 尺寸 (W×H) | 说明 |
| --- | --- | --- | --- |
| 标记 Mark | (0.97, 17.96) cm | 2.16 × 0.19 cm | 左下角。放**你自己的**字标／缩写／短标签 |
| 日期 | (26.09, 17.74) cm | 4.10 × 0.50 cm | 右对齐 |
| 页脚文本 | (6.61, 17.74) cm | 15.60 × 0.50 cm | 居中 |
| 页码 | (30.88, 17.74) cm | 2.00 × 0.50 cm | 右对齐 |

### 左下角标记 Mark

这个位置原本是品牌字标。这里没有品牌资产，规则是通用的：

1. **只放用户自己的**字标、缩写或短标签。**绝不放任何第三方公司的 logo 或品牌标识。**
2. 用真实图片文件，不要用文字假装别人的 logo。
3. 有真实字标图时：不改色、不拉伸、不旋转、不加特效，**保持原始宽高比**；亮背景用黑色版，暗背景用白色版。
4. 没有字标就用一行 8–9pt 的字距小标签（如 `READING NOTE`），居左。
5. 宽度不小于 1.5 cm，四周留出净空；不要放在杂乱背景上。

### 页脚文本格式

```
标题 | 姓名, 团队 | 组织 | 密级/说明
```

四段都填实际内容，不要留占位符，也不要整段省略。

### 其他页面类型

| 类型 | 分割线 | 页脚 |
| --- | --- | --- |
| 内容页（绝大多数） | 有 | 四个元素齐全 |
| 标题页 | 有 | 有标记／日期／文本，**页码隐藏** |
| 图片标题页 | 有 | 只保留标记 |
| 结尾页 | **无** | **无页脚**，只有居中大标记 (14.31, 9.28) cm，5.25 × 0.50 cm |

**结尾页只有居中的标记，别的什么都没有**——不要标题、不要"谢谢观看"、不要分割线、不要页码。

## 配色

黑白承载主体，中性色柔和支撑，强调色是信号不是装饰。

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 基础 | `#000` `#fff` | 主要文本、表面、呼吸空间 |
| 暖中性 | `#FCFAF7` `#F6F4F1` | 冷静背景、章节底、纯白过于刺眼的区域 |
| 灰阶 01–06 | `#5A5A5A` → `#D6D6D6` | 次要文本、边框、元数据 |
| Signal 蓝 | `#1F4E79` | 链接、交互、选中态、主要数据焦点 |
| Alert 橙 | `#B25219` | 警示、关键强调——谨慎使用 |
| Deep | `#10202E` | 暗色表面、暗色主题底 |

完整色板与使用规则见 [`references/color-palette.md`](references/color-palette.md)。

### 亮色与暗色主题

- **亮色（默认）**：白底、黑字、黑色标记。大部分报告和标准内容用它。
- **暗色**：`--deep` 底、白字、白色标记。用于主题演讲、产品展示、图片为主的场景。
- **同一份文稿中不要混用**，除非有刻意的叙事理由（比如亮色文稿里插一个暗色章节分隔页）。

### 色彩硬规则

1. 同一元素中**不混用**两个强调色。
2. **不做**强调色之间的渐变。
3. **不把颜色当作唯一的信息载体**——必须配标签、图标或纹理。
4. 不用彩虹色板，不用装饰色块。
5. 不确定时就少用。强调色是信号，不是装饰。

## 布局与组件

- **宽松的边距与留白**——这本身就是主要设计元素。
- **编辑式构图**，不要做成密集仪表盘。
- 分区顺序：开篇 → 支撑细节 → 证据 → 行动区 → 安静的页脚。
- 用**细腻分割线**而不是厚重的容器；可以做模块化区块，但不要做成一排一模一样的卡片。
- 细边框 `1px solid var(--grey-06)`；圆角 2–6px，绝不气泡感。
- 阴影：无，或极轻 `0 1px 3px rgba(0,0,0,.06)`。
- 图标极简、功能性，不要装饰性插画。

## 数据可视化

不是所有数据都需要图表。按顺序判断：

1. **单一数字**就是信息 → 用大数字。
2. **比较足够简单** → 用一句话。
3. **类别比较／排名** → 用简单柱状图。
4. **模式、趋势、关系** → 才用复杂图表。

图表色彩：坐标轴／网格用灰阶，主数据焦点用 Signal 蓝，警示／阈值用 Alert 橙且克制，冷静信息区用浅蓝。
**禁止**彩虹色板、渐变、阴影、装饰性样式。数据元素用直角，交互元素用圆形。

详见 [`references/dataviz-guide.md`](references/dataviz-guide.md)。

## 快速开始

直接用 [`assets/slide.html`](assets/slide.html)：一份可运行的单页 16:9 模板，已实现全部网格坐标、
页脚四元素、亮暗主题和打印尺寸。改内容即可，不要重写版式。

[`references/web-artifacts.md`](references/web-artifacts.md) 解释了模板里那个随容器缩放的坐标写法、
如何导出成一页 PDF，以及怎么验证渲染结果——版式脆，交付前必须验证。

## 交付前检查清单

- [ ] 设计冷静、高级，不喧哗
- [ ] 黑白承载基础，中性色柔和支撑
- [ ] 强调色只出现在需要信号的地方，没有主导构图
- [ ] 同一元素内没有混用强调色，没有强调色渐变
- [ ] 布局宽松且有结构，层级不依赖颜色也成立
- [ ] 标题 32pt、常规字重、距左约 1 cm／距顶约 2 cm
- [ ] 正文遵循 16 / 14 / 12 / 11pt 层级
- [ ] 上分割线 y=1.55 cm、下分割线 y=17.50 cm，全出血，0.25pt 且未超粗
- [ ] 分割线没有使用强调色
- [ ] 左下角标记存在、位置正确、未被修改，且**不是任何第三方品牌标识**
- [ ] 页脚四元素齐全，位置精确，全篇一致，页码可见
- [ ] 结尾页只有居中标记，无分割线、无页脚
- [ ] 图表只在增加洞察时使用，简洁、有目的、可访问
- [ ] 颜色不是唯一的信息载体
- [ ] 所有视觉噪音已移除

任何一项不过 → **简化设计**。
