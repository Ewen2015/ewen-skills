# 色板参考

这套色板是一套通用的斯堪的纳维亚设计语言，不绑定任何品牌。所有值可直接复制使用。

## CSS 变量

```css
:root {
  /* 基础 */
  --black: #000000;
  --white: #ffffff;

  /* 暖中性 —— 纯白过于刺眼的表面 */
  --warm-white: #FCFAF7;
  --paper: #F6F4F1;

  /* 灰阶 01–06 */
  --grey-01: #5A5A5A;
  --grey-02: #6E6E6E;
  --grey-03: #8A8A8A;
  --grey-04: #A3A3A3;
  --grey-05: #BFBFBF;
  --grey-06: #D6D6D6;

  /* 强调色（信号） */
  --signal: #1F4E79;
  --signal-soft: #A9C3DE;
  --signal-wash: #EDF2F8;
  --alert: #B25219;

  /* 互补 */
  --deep: #10202E;
  --moss: #6E7A66;
  --clay: #B08A6A;
}
```

## 基础色

| 名称 | Hex | 用途 |
| --- | --- | --- |
| Black | `#000000` | 主要文本、强对比、结构强调、编辑感 |
| White | `#ffffff` | 清晰表面、分隔、呼吸空间、高对比布局 |

**大部分设计由黑白承载，中性色辅助。** 如果一张页面拿掉所有灰色和强调色之后依然成立，说明结构是对的。

## 暖中性色

| 名称 | Hex | 用途 |
| --- | --- | --- |
| Warm White | `#FCFAF7` | 冷静背景、编辑表面、纯白过于刺眼的页面 |
| Paper | `#F6F4F1` | 柔和章节底、安静内容区、细腻的表面变化 |

暖中性色是这套风格的体温。用它们替代纯白做整页底色，页面会立刻安静下来。

## 灰阶

| 名称 | Hex | 用途 |
| --- | --- | --- |
| Grey 01 | `#5A5A5A` | 次要文本、元数据（白底对比度约 7.4:1） |
| Grey 02 | `#6E6E6E` | 支撑标签 |
| Grey 03 | `#8A8A8A` | 中调次要内容、小标签 |
| Grey 04 | `#A3A3A3` | 分割线、更轻的元数据 |
| Grey 05 | `#BFBFBF` | 细腻边框、禁用状态 |
| Grey 06 | `#D6D6D6` | 最浅边框、弱化元素 |

同样的灰在暖底色上会比在白底上偏冷，必要时整体上移一档。
**禁止**在降低可读性的地方使用浅灰——正文不要低于 Grey 02。

## 强调色（信号）

| 名称 | Hex | 用途 |
| --- | --- | --- |
| Signal | `#1F4E79` | 链接、交互、选中态、主要数据焦点、方向性强调 |
| Alert | `#B25219` | 警示、阈值、需要高关注度的细节 |

两个强调色都经过对比度检查：Signal 在白底约 8.7:1，Alert 约 5.1:1，均可直接用作正文色。

### 强调色规则

- **不要**在同一元素中同时使用 Signal 和 Alert。
- **不要**在强调色之间做渐变。
- 两者同时出现时必须用白色或中性空间明确隔开。
- 不要因为"可以用蓝"就到处用蓝。
- 不要用 Alert，除非信息确实需要被注意到。
- **绝不让强调色主导构图。**

## 互补色

| 名称 | Hex | 用途 |
| --- | --- | --- |
| Deep | `#10202E` | 暗色主题背景、严肃/高级强调 |
| Signal Soft | `#A9C3DE` | 冷静信息区、Signal 的延伸 |
| Signal Wash | `#EDF2F8` | 安静的信息强调、细腻背景 |
| Moss | `#6E7A66` | 自然、材质感；可选的第二中性 |
| Clay | `#B08A6A` | 温暖、材质感；谨慎使用 |

Moss 和 Clay 是可选的自然色，用它们替代彩色强调色，能保持北欧调性。
不要用它们替代 Alert 的警示语义。

## 色彩误用（禁止）

- 同一元素中使用两个强调色
- 强调色之间的渐变
- 浅灰降低可读性
- 彩虹色板
- 装饰性色块
- 把颜色当作装饰
- 仅用颜色传达含义
- 过度设计的色彩系统
- 颜色压过内容

**颜色应澄清、信号、引导，不应装饰。**

## 亮色与暗色主题

| | 亮色（默认） | 暗色 |
| --- | --- | --- |
| 背景 | `#ffffff` / `#FCFAF7` | `#10202E` |
| 文本 | `#000000` | `#ffffff` |
| 次要文本 | Grey 01–02 | Grey 04 |
| 分割线 | 黑，0.25pt | 白，0.25pt |
| 标记 | 黑色版 | 白色版 |
| 强调 | Signal / Alert | 用 Signal Soft 提亮以保证对比 |

同一份文稿中不要混用，除非有刻意的叙事理由。暗色主题下强调色要提亮，
否则在深底上会失去对比。
