# 创作者中心实测选择器（2026-10 实测）

下面全部是**真机测出来的**，不是从文档抄的。实测环境：账号「司马读书」（笔记管理显示 244 篇），
Chrome + XHS Bridge 扩展。页面改版时按这张表修 `scripts/xhs_state.py`。

## 笔记管理页

`https://creator.xiaohongshu.com/new/note-manager`

| 元素 | 选择器 | 备注 |
| --- | --- | --- |
| 页签 | `.tab-item` | 文本为 `全部 244` / `已发布` / `审核中` / `未通过`；当前页签多一个 `tab-item--active` |
| 卡片 | `.note-card` | 一屏约 10–20 张，**滚动才继续加载** |
| 标题 | `.note-card__title` | |
| 时间 | `.note-card__time` | `2026-10-05 22:00` |
| 定时标记 | `.note-card__schedule` | 只在定时笔记上出现，文本就是「定时发布」 |
| 五项数据 | `.note-card__row--stats .note-card__stat span` | 顺序固定：**阅读 / 评论 / 点赞 / 收藏 / 分享** |
| 笔记 ID | `data-impression` 属性 | 值是 HTML 转义过的 JSON，取 `.noteTarget.value.noteId` |

### 三个必须知道的坑

**1. 状态只能靠页签，卡片上没有可靠的状态文本。**
卡片上的 `is-show-audit="isShowAudit"` 属性**所有**卡片都有（已发布的也有），
拿它判断审核状态一定会出错。判断"是否卡审核"的可靠做法是切到 `审核中` 页签、
按上面的 `noteId` 做交集。

**2. 定时发布的笔记不在"已发布"页签里。**
发布时间没到之前，它出现在 `全部`（带 `.note-card__schedule`），
同时通常也在 `审核中`。所以找定时队列必须扫 `全部`，扫 `已发布` 会一无所获。

**3. 数据是懒加载的，不滚动就等于只看了一屏。**
实测账号 244 篇笔记，一屏只渲染 10–20 张。脚本用滚动 + 连续三次不增长才停的方式收集，
但 `--max` 给太小仍然会漏，报告里必须如实说扫了多少张。

## 草稿箱（发布页）

`https://creator.xiaohongshu.com/publish/publish?source=official&target=image`

| 元素 | 选择器 | 备注 |
| --- | --- | --- |
| 入口 | `.draft-title` | 文本 `草稿箱(1)`，点击打开抽屉 |
| 抽屉 | `.draft-drawer` | |
| 遮罩 | `.d-drawer-mask` | 点它关闭抽屉 |
| 类型页签 | `.draft-tabs .tab-item` | `视频笔记(1)` / `图文笔记(0)` / `长文笔记(0)` / `播客笔记(0)` |
| 草稿条目 | `.draft-list .draft-item` | |
| 条目标题 | `.draft-item .draft-title-text` | |
| 条目时间 | `.draft-item .draft-time` | `保存于2026-02-02 23:07:54` |

页面原文写得很清楚：**「草稿存储于当前使用的浏览器本地，在清除浏览器数据时会被删除」**。
所以草稿箱既不跟账号走、也不是可靠库存——要留就落成 `posts/` 里的成品目录。

类型要分清楚：只有 `图文笔记` 的草稿能直接用于图文发布，
`视频/长文/播客` 草稿是别的发布形态，不能算作图文的库存。

## 定时发布本身

定时开关与时间选择器在发布页（`.post-time-wrapper .d-switch`、`.date-picker-container input`），
属于 `rednote-post` 的发布流程，本 skill **只读不写**，不要在这里点它们。

## 排障顺序

某个页签读出 0 条时，按这个顺序查，别一上来就怀疑选择器：

1. 浏览器是不是停在别的页面上？（`queue`/`history` 每次都会重新导航，`drafts` 会跳到发布页）
2. 登录是不是过期了？（页面上会出现登录二维码）
3. 这个页签是不是**本来就空**？（实测中「审核中」在笔记过审后就是 0 条）
4. 以上都不是，才去比对选择器是否改版。
