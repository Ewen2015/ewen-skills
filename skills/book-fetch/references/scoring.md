# 综合评分口径

一本书的候选清单里，**书名最像正版的那条常常不是正版**。
评分表的作用就是把这些差异摆到明面上，让用户两分钟能做完决定。

总分 100，六维。每一维都给出**扣分理由**，不接受"综合来看比较好"。

## 六个维度

### 书目匹配 /25

| 判据 | 分值 |
| --- | --- |
| 书名包含目标书名 | +10 |
| 书名以目标书名开头 | +2 |
| 作者命中（词序无关，`Sagan, Carl; Druyan Ann` 也算命中 `Carl Sagan`） | +8 |
| ISBN 命中已知版本 | +5 |

作者匹配特意做成**词序无关的全词包含**：书源里的作者字段写法很乱
（`Sagan Carl`、`Sagan, Carl; Druyan Ann`、`Carl Sagan`），
按字符串相等会全部判为"未匹配"。

### 版本完整 /20

出版社存在 +5；年份存在 +4；语言符合 `prefs.json` +6（不符则 +3 并注明）；
格式为 epub +5（epub 通常对应完整电子版，不是摘编或纸质扫描）。

### 文本可提取 /20 —— 最重要的一维

| 格式 | 分 | 含义 |
| --- | --- | --- |
| epub | 18 | 通常带文字层，可直接抽取做笔记与卡片 |
| pdf | 11 | **文字层未知**；扫描件要 OCR，成本高一个数量级 |
| azw3 / mobi | 8 | 需要先转换 |
| 其他（djvu 等） | 5 | 不划算 |

这一维决定这个文件能不能顺利进入后面的流水线，所以权重给到 20，
和"版本完整"持平——比"可得性"重要一倍。

### 文件线索 /15

同格式候选少于 3 条时给 8 分（没有比较基准，不硬判）。

有 3 条以上时与**同格式中位数**比较：

| 比值 | 分 | 提示 |
| --- | --- | --- |
| ≥ 3× | 12 | 远大于中位——有图版的书通常如此，优先 |
| 0.75×–3× | 12 | 与中位相当 |
| 0.4×–0.75× | 7 | 明显偏小，可能删图 |
| < 0.4× | 2 | 远小于中位，疑删图或节本 |

**这是启发式，不是事实。** 它的价值在于把"2.21 MB vs 330 KB"这种差异
摆到用户面前，而不是替他决定。

### 元数据完整 /10

`title / author / language / extension / year / publisher / identifier / size`
八个字段有值的比例。

### 可得性 /10

可直接下载 +10；需要登录账号 +5；可尝试 +7；当前不可下载 +2。

**需要登录不是缺点**，但在用户还没决定要不要登录时，它是必须知道的信息。

## 剔除规则（不进候选）

命中以下任一即出局，并在报告「已剔除」里列出原因：

- 英文：`study guide`、`summary`、`workbook`、`quicklet`、`cliffsnotes`、
  `sparknotes`、`companion to`、`works by …`、`complete works`、
  `annotated bibliography`、`shmoop`
- 中文：`导读`、`速读`、`精读笔记`、`摘要`、`解读版`、`节选`

判断依据是 `title + author + publisher` 拼在一起的文本，不只看标题。

**为什么必须剔除**：这类书的标题往往比正版更长、更像样
（例如 `Works by Carl Sagan (Study Guide): Cosmos…, Pale Blue Dot, …`），
不剔就会排在正版前面。

## 去重与并列

- 去重键：`identifier`（ISBN 列表）或 `hash`，取分数高的一条。
- 同分时的并列规则，按顺序：
  1. ISBN 命中已知版本优先；
  2. 同格式里更大者优先（有图版的书文件自然更大）；
  3. 保持原始顺序。

并列规则会体现在排序结果里，但**不会改变总分**——用户看到的分数是六维原始分。

## 怎么改这张表

改权重前先问：**这条改动会让用户更容易还是更难做决定？**

- 想要更重视图版 → 提高「文件线索」或给 epub 的图片存在加一维；
- 想要更重视权威版本 → 提高「版本完整」的出版社权重；
- 想加"版次是否最新"→ 需要更可靠的书目数据，现在只有公共书目 API，先别加。

改完要在本文件里写一条记录：改了什么、为什么、观察到了什么变化。
`rsi-reading` 的改进项也应该落到这里。
