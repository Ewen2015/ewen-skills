# AI 味清单：从哪看出来，怎么改

**AI 味不是"写得不好"，是"写得不像某个人"。** 模型默认吐出来的是一锅平均腔：
论述有套路的连接词、密度均匀的长句、每段一句金句、结尾来个总结。它读起来"很完整"，
但没有任何一个人的体温。

这份清单分两层：

- **能机判的**——词表和几类结构信号，在 [`../scripts/human_check.py`](../scripts/human_check.py) 里，
  跑一次就知道。下面的词只是**例子，完整表以脚本为准**（判据落在脚本里，不靠背）。
- **只能靠念的**——节奏、语气、像不像在说话。脚本查不出，见最后一节。

---

## 1. 词层

### 1.1 AI 味连接词／论述套路

模型用它来"承接"，人不这么说话。一出现就不像人：

| 类别 | 例子 | 改法 |
| --- | --- | --- |
| 收束总结 | 综上所述／总而言之／总的来说 | **删掉**。要收，就用一句具体的话收，别用"综上" |
| 提示注意 | 值得注意的是／值得一提的是／不容忽视 | 删掉，直接说那件事 |
| 推出结论 | 由此可见／不难发现／不难看出 | 删掉，让事实自己说话 |
| 抬共识 | 众所周知／毋庸置疑／毫无疑问／显而易见 | 删掉，或换成"我（/书里）认为" |
| 拉人入伙 | 让我们一起／不得不说的是 | 删掉——除非你真的是在跟读者一起做同一件事 |
| 时代背景 | 在当今社会／随着……的发展／在这个……的时代 | 换成具体的时间／数字／场景 |

### 1.2 行话

不是给读者省力，是给自己省事。**读者读到行话只会觉得你在装。**

| 行话 | 说人话 |
| --- | --- |
| 赋能 | 帮、让……能做到 |
| 底层逻辑 | 真正起作用的那个原因 |
| 抓手 | 从哪儿下手 |
| 闭环 | 走完一轮、能自己接上 |
| 颗粒度 | 细到什么程度 |
| 对齐 | 说清楚、对一遍 |
| 打法 | 怎么做 |
| 组合拳 | 几招一起上 |

（行话表还在长。**这个词是不是行话，判据是"一个没读过这行的人认不认识"**，
不是"它是不是出现在某个禁词表里"。）

### 1.3 空词／副词滥用

极大地、有效地、显著地、深度、全方位、多维度——**删掉它们，句子一点没少**。
真要有量级，就上数字。

## 2. 结构层

1. **排比三连。** "既要……又要……还要……""不仅……而且……还……"。
   人不这么凑齐三样，人会挑最要命的那一样说。**列三样时，每样后面接一个具体的例子**，
   而不是三个抽象名词并排。
2. **总分总。** 开头概括、中间分点、结尾总结。**开头改成具体的场景或数字**，
   结尾回到读者身上而不是总结内容。
3. **每段一句金句。** 密度均匀的"点睛句"读起来像 PPT。**一篇留一句就够**，
   其余段落老老实实讲事。
4. **把什么都列成清单。** 能推进的段落就用段落推进；清单是给"并列的东西"用的，
   不是给"有先后的东西"用的。
5. **对仗的小标题。** "三个误区／两条路径／一个真相"——标题越整齐，越像模板。

## 3. 语气层

| 味道 | 长什么样 | 改法 |
| --- | --- | --- |
| 教程腔 | 接下来我们来看／下面让我们 | 直接进入内容，不报幕 |
| 客服腔 | 希望对你有帮助／如你所见 | 删 |
| 留后路 | 可能／也许／某种程度上／在某种意义上 | 要么给证据把话说实，要么把断言缩小到能负责 |
| 过度礼貌 | 不妨／请允许我／借此机会 | 删 |
| 惊叹 | ！太多、emoji 每句一个 | 重音用少而准，别当气氛组 |

**和"留后路"是一体两面的那条硬线**：不确定就核实、把断言收缩、或删掉，
**不写"待核实／需查证"**——读者要的是结论，不是你的工作进度。

## 4. 节奏层：匀称本身就很像 AI

模型写出来的句子长度惊人地一致，段落也常常一样长。**人说话是有起伏的**：
一个长句铺开，下一句三个字砸下来；有时候一句单独成行。

- **长短交替**：写完一段，数一下句子长度，如果都在 20–30 字，拆一两句。
- **该断就断**：重点句让它自己站一行（这也是小红书正文唯一能用的重音之一）。
- **段落别一样长**：整篇的段落长度极差太小，脚本会提醒。
- **别把条目做成模板**：每条观点都"判断句 + 一句所以怎么用"，四段一模一样长——
  内容没错，读起来是 PPT。**阈值是量出来的**（20 篇已发成品，见下表）。

### 4.1 结构信号的阈值（照着已发成品量的，不是拍的）

| 信号 | 已发成品里的最大值 | 脚本判定的下限 | 为什么是它 |
| --- | --- | --- | --- |
| `→` 领起的"所以怎么用"行 | 3 条（prisoners） | > 3 条 | 每条都配一个行动项，就成了零件表 |
| 同一个 emoji 领起的段数 | 2 段（creative-act、yujun） | > 2 段 | 重音符号被用成了编号 |
| 破折号密度 | 0.7 处／100 字 | > 1.2 处／100 字 | 连着来的破折号，是在替想不出的转折找台阶 |
| 段落长度极差／均值 | 1.09–2.92 | < 0.25 | 整篇每段一样长 |

**这三条是软的**（默认只提醒），但 `human_check.py --strict` 下判失败，
`rednote-post` 的 `check_content.py` 也按失败算——发布流水线不留活口。
20 篇已发成品在 `--strict` 下全部 0 命中，所以不会误伤真品。

## 5. 标点层

- **破折号滥用**——"——"连着来，是模型在替你想不出的话找台阶。删到只剩真的转折。
- **冒号列表**——"三件事：一、……二、……"能改成一段人话就改。
- **引号不统一**——直角引号「」与弯引号""混用；一篇里选一套。
- **省略号**——"……"用在犹豫处是对的，用在"话没说完"的偷懒处就是 AI 味。

## 6. 综合示例

**改前（AI 味）：**

> 在当今这个快节奏的时代，阅读一本好书变得越来越重要的同时，也变得越来越难。
> 首先，我们要理解这本书的底层逻辑；其次，要找到可以落地的抓手。
> 综上所述，读完这本书，我们既要有输入，又要有输出，还要有反思。
> 让我们一起在阅读中成长吧！

**改后（人话，具体、有起伏、有取舍）：**

> 这本书我在通勤路上读了两周，一天读一章。
> 它真正教我的只有一句话：先做，再判断。
> 剩下的三百页都在解释这句话为什么难——
> 因为我们习惯了一边做一边解剖自己。

改了什么：删了全部连接词与行话；把"输入／输出／反思"换成"通勤、两周、一天一章"；
拆了排比三连；留了最多一个重音（"先做，再判断"单独成行）。

## 7. 脚本查不出的那一半

跑完 [`../scripts/human_check.py`](../scripts/human_check.py)（0 通过）之后，还有一次**出声念**：

1. 念起来像一个人在跟朋友讲话，还是像一篇稿子？
2. 有没有哪句是"为了完整"而留下的？——删掉它，别人不会发现。
3. 每一段都能指到一样具体的东西吗（场景／数字／页码／动作）？
4. 结尾是回到读者身上，还是在总结内容？
5. 通篇有没有一句你会真的想记住的话？——只需一句。

**脚本给的是下限，念一遍给的是上限。**
