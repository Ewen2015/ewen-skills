# 数据可视化指南

## 决策框架

做任何图表之前先问：**这份数据需要可视化吗？**

每个图表都增加认知负担。用能传达要点的**最简单**形式：

1. **单一数字／大指标** → 用大数字，不要画图
2. **简短比较** → 用一句话
3. **类别比较／排名** → 用柱状图
4. **模式、趋势、关系** → 才用相应图表

## 何时该用图表

当读者需要看到：随时间变化、跨类别比较、排名、分布、量级、部分与整体、
目标进度、异常值、变量间的关系。

**避免图表**当：单一数字就是信息；一句话更清晰；简单表格更易比较；
图表需要额外解读；可视化增加复杂度但没增加洞察。

## 图表类型选择

### 柱状图
比较、分类、排名、跨类别的精确值。变体：垂直、水平、堆叠、分组。
**标签长或类别多时用水平柱。**

### 折线图
趋势、随时间变化、预测、连续数据。变体：单线、多线。
单图线条不要过多；杂乱时筛选或拆成多个小图。

### 面积图
带量级的趋势、随时间变化的整体构成。谨慎使用，容易视觉沉重。

### 环形图
简单的部分与整体、总数清晰的百分比。
类别过多、需要精确比较、数值相近、总数无意义时不要用。

### 进度指示器
警示、监控、目标／阈值进度。变体：线性条、环形、仪表盘。
谨慎使用，让状态**立刻**可理解。

### 大数字／指标卡
一目了然的关键指标、单一重要值、紧凑概览。变体：单指标、带变化值、带趋势、带状态。
**当单一值是主要信息时，优先于任何图表。**

## 三种可视化模式

| 模式 | 洞察时间 | 适用于 | 使用 |
| --- | --- | --- | --- |
| 简化（一目了然） | 2–3 秒 | 移动端、仪表盘、演示、摘要 | 大数字、紧凑柱、迷你图、最少标签 |
| 标准（分析） | 20–30 秒 | 报告、分析页、比较视图 | 清晰坐标轴标签、描述性标题、简单图例 |
| 复杂（深度探索） | 数分钟 | 分析工具、运营分析、企业报表 | 筛选、搜索、提示、数据表、下钻、多个小图 |

演示场景默认用**简化**模式。报告页可以用**标准**。

## 图表色彩

| 元素 | 颜色 |
| --- | --- |
| 坐标轴、网格线 | Grey 04 `#A3A3A3` 或 Grey 05 `#BFBFBF` |
| 标签、次要文本 | Grey 01 `#5A5A5A` 或 Grey 02 `#6E6E6E` |
| 非活动／背景系列 | Grey 05 `#BFBFBF` 或 Grey 06 `#D6D6D6` |
| 主要数据焦点 | Signal `#1F4E79` |
| 警示／阈值 | Alert `#B25219`，克制 |
| 冷静信息区 | Signal Wash `#EDF2F8` 或 Signal Soft `#A9C3DE` |
| 表面背景 | Warm White `#FCFAF7` 或 Paper `#F6F4F1` |

**禁止**：彩虹色板、渐变、阴影、装饰性样式、图表垃圾。

同一图表里最多用一个强调色。需要区分系列时，优先用灰阶深浅，
再考虑用 Signal 的单色调阶梯，而不是引入第二个色相。

## 形状规则

- **直角**：数据元素（柱、进度条）——表示分组数据
- **圆形**：交互元素（提示、指针、按钮）
- **环形／仪表盘**：本质为圆形，是例外

保持几何简洁且功能性。

## 无障碍

- 使用描述性标签和简单图例
- **绝不只靠颜色**传达关键含义——必须加标签、图标、图案或注释
- 跨设备和查看条件保持可读性
- 使用可访问的对比度（正文 4.5:1 以上）
- 在相关场景支持悬停、键盘、屏幕阅读器和触摸
- 限制每图的数据系列；用筛选或多个小图，而不是挤在一起

## 监控与探索

**监控（状态追踪）**：优先一目了然的清晰度；保持周围数据视觉中性；
颜色只用来高亮真正重要的东西；让当前状态快速可理解。

**探索（深度分析）**：允许跨类别和时间比较；在有用时提供筛选、提示、下钻；
给足标题和上下文；把可见的模式翻译成有意义的结论。
