# 一、外 · 脉络

## 1. 目的

表面目的是**给一套方法**：如何由「文本、表征（表相）」去看产生它们的「社会情境（本相）」及其历史变化。作者给这套方法起了名字，叫**反思史学**（reflexive historiography）。

作者自己列了三个层次的目的：

1. **给学界**——一份「研究方法指南」，把史学与人类学接起来（他的副标题是「在文献中作田野」）。
2. **给一般读者**——练就「孙悟空的火眼金睛」，看透「凡尘世界变幻万端的表相」，认识表相下的本相。
3. **给他自己**——在写完那四本书之后，回头自问：我凭什么说我得到的结论是对的？我的分析逻辑为什么合理？为什么我认为这些知识有助于社会更和谐、更公平？

**要说服的对手**是两层：一层是「历史事实就是过去发生的事」这种素朴实证主义（他花了整整第一章拆它）；另一层是学术圈里把理论讲得拗口、与社会脱节的风气（他明说「将学术由云端拖到尘世间来……是反思性研究的要务之一」）。

## 2. 思潮脉络

- **1980 年代中期的「表述危机」（crisis of representation）。** 这是本书最直接的西方语境：马库斯与菲舍尔《作为文化批评的人类学》、克利福德与马库斯编的那本论文集，承认民族志里的「真实」最多只是**部分真实（partial truth）**。作者引德勒兹对福柯说的话——「为他者发言是一种轻侮」——来点出问题的根：我们无法正确无误地描述外在事物。
- **社会记忆研究**（从哈布瓦赫的「集体记忆」起，到康纳顿《社会如何记忆》），近三十年成为人文社科的焦点。本书第五章整章是这条线。
- **实践理论**：布迪厄的习性／习行（habitus / practice），以及他那句被本书反复用的 the reality of representation and the representation of reality。
- **中文世界的处境**：族群认同、民族主义、国族建构在 1990 年代以后的两岸学界都是热题；台湾解严后的本土史学转向，也是作者的问题意识来源之一。

## 3. 作者的思想脉络

- 学术训练在**历史系所**（大学与硕士），所以他自称「我是具有『学院式的』历史学训练的人」；后来进**人类学研究所**教书（在台湾一所大学人类学所开「文本分析」课，「在文献中作田野」就是那门课的副标题）。
- **1990 年代起**在川西岷江上游做羌族的历史人类学田野——这是全书几乎所有例子的来源。
- **2005–2006 年访问哈佛**期间完成初稿，之后**又改了将近九年**才出版（谢词里自己交代）。
- 这条脉络解释了这本书的形态：**它是从田野和写作里倒推出来的方法论**，不是先有理论再找例子。

# 二、内 · 正文

## 7. 书目与分类

**论说性，兼实用性**。它不是纯理论著作，也不是纯方法手册，而是**用中文世界读者熟悉的材料（《史记》《华阳国志》、方志、族谱、羌族服饰与祭仪）演示的一套分析程序**。作者明说这是为中文读者写的文本／表征分析著作。

## 8. 一句话主旨

**我们看见的「历史」不是过去发生的事，而是在特定社会情境下被人写出来、被社会记住、又反过来支撑那个社会情境的一层表相；史学的工作不是争论这层表相的真假，而是把它当成一份「社会记忆的遗存」，去还原产生它的本相。**

## 9. 全书大纲

| 章 | 内容 | 要点 |
| --- | --- | --- |
| 前言 为什么赤脚惯了踩在锐石上不知痛？ | 问题意识 | 茧的比喻：身体会生出老茧隔绝刺激，心也会；知识体系更像一个虚拟世界，人们住在里面而不知道「历史」正是它的地基 |
| 一 事实与现实 | 拆概念 | 「历史」一词两义（过去发生的事／人们记得叙述的事）；事实、真相、现实三分；「现实」常指**社会现实**，即本相 |
| 二 典范与边缘 | 知识社会学 | 典范历史不是最真实的过去，而是**最符合当前社会现实**、最能反映人们对未来的希望的那一套；边缘是突破典范的入口 |
| 三 人类社会的基本面貌 | 框架 | 环境／领域资源 → 经济生业 → 社会结群 → 文化表征，四者环环相扣构成**人类生态**（human ecology） |

| 五 认同与记忆 | 机制 | 社会记忆为什么存在（认同与区分）、如何传递（语文／物像／仪式／日常行为）；四个层级的概念：社会记忆 → 集体记忆 → 历史记忆 → **根基历史记忆** |

## 10. 作者要解决的问题

**主问题**：我们能不能，以及如何，通过留存下来的文本与表征（表相），去认识产生它们的那个社会（本相）——尤其是在**时间与空间上都已经不可亲临**的那些社会？

**次问题**：

- 为什么人们会相信一些明显可以质疑的「历史」，甚至受害者也接受自己被边缘化的身份？（茧的问题）
- 一位历史学者／人类学者凭什么说自己无偏颇？（作者把这一问指向自己）
- 文本为什么会有那么多「结构」——为什么许多人各自写出的正史、方志、族源传说，形状会那么像？

## 11. 关键词表

作者赋予了特定词义的几个字，是全书的钥匙：

| 词 | 作者在这本书里给它的意思 |
| --- | --- |
| **历史 vs「历史」** | 无引号的是「过去真正发生的历史」；加引号的是「人们记得的、叙述的、书写的『历史』」。全书几乎都工作在后者 |
| **事实 / 真相 / 现实** | 事实＝真正存在或发生过的（但我们的质、量、时空概念都是人为建构）；真相＝为事实所作的注解与描述，因而受争议、有立场；现实（reality）本书取「社会现实」义 |
| **表相 / 表征** | 人们的行为、外貌、言谈、物像所造成、可被观察并在人心中产生特定意义的外在景象。是**双方面的联结**：外在景象 ＋ 它因社会情境而在人心中造成的共同意象、信念或情感 |
| **本相 / 社会现实** | 人们难以察觉的社会真实面貌。多重的社会与文化区分（西方／东方、男／女、富人／穷人、汉族／少数民族）叠在一起构成的那种现实 |
| **习行 / 习性** | 布迪厄的实践（practice）与习性（habitus）：习性是在某种社会本相中产生的行为「结构」，让人不知不觉按某种模式作为，其产物又强化原来的本相 |
| **文本 / 情境** | 文本不是「文献」（成篇文字）的替用词，它包括口语、图像、仪式、身体、行为；情境则是产生文本并给它赋意的那套社会本相 |
| **文类** | 对应较复杂、多元社会情境的文本结构（如正史、方志、族谱、民族志）。作者明说这本书本身也是「一种文类」 |
| **历史心性** | 更深一层、更难察觉的文本结构，规范人们如何想象、建构「历史」。两种：**弟兄祖先**（资源对等、人群分散平等）与**英雄祖先**（资源与权力集中、社会阶序化） |
| **模式化叙事情节** | 与较单纯社会情境对应的书写结构（如方志士女传里「为不失节而自杀」的情节） |
| **根基历史记忆** | 描述一群人之共同血缘、空间资源的起源与延续变迁的历史记忆。叙事符号就两个：**血缘**与**资源**。「黄帝子孙历史」也是一种根基历史 |
| **历史性** | 利科的意思：我们创作历史，沉浸其间，又成为历史的生成物。正因如此，我们才「相信」我们创造出来的「历史」为真 |
| **表述性知识 / 默示性知识** | 「你说的是什么？」问的是表述性讯息；「你到底想说什么？」问的是默示性讯息——那一层经常在双方意识之外，因而它所强化的本相根深柢固 |

## 12. 关键主旨

1. **「历史」一词两义，混淆这两个意思是所有争论的源头之一。**（第一章）写一部美国史的起点若定在「五月花号」，印第安人就成了被征服者、后来的亚非移民就成了新移民——**每一句都是历史事实，但把它们组构成一个「历史」是另一回事**。反过来写也可以没有一句虚构。
2. **本相产生表相，表相强化本相，两者都在人们意识之外进行。**（第四章）男性中心主义的社会里，女性也会说出歧视女性的话；一则信用卡广告里的「东方」——混乱、贫穷、落后——本身就是西方中心主义表相，而东亚观众看了还觉得幽默、还对这家公司多了好感。
3. **本相为什么看不见：因为习性让人「习而不察、为而不知所为」。**（第四章）茧的比喻在这里落地——不是有人瞒着你，是你自己长出了隔绝刺激的那层皮。
4. **文本结构是社会现实本相的另一层遮掩物。**（第七章）一个作者一心一意想写一部好方志，他很难察觉自己是在**摹拟并强化郡县（作为帝国一部分）的社会现实**。
5. **「文本」是我们了解过去的唯一通路，而它同时也是遮蔽物。**（第八章）作者把它比作考古器物：要先研究它的「生命史」——选材、制作、使用、保存、废弃与再利用——每一段都对应一套社会情境。
6. **要看见凹凸镜，只能「移动」。**（第八章）从一个田野点移到另一个，观察社会本相与文本表征**相对**的变化；固定的观察只能得到一个偏见，移动比较才让偏见显形。这也让民族志与史学的主张第一次有了可被验证的参照。
7. **「边缘」是突破典范知识的关键点。**（第八章）重大变迁的边缘时间、核心之外的边缘空间、时代里的边缘人物、不合文类典范的边缘文本——典范知识让我们把这些当异端或微不足道的异例，而它们恰恰是典范虚构之处的入口。
8. **知识论上要谦虚。**（第九章）作者明确说自己**不能肯定**羌族的弟兄祖先历史「从未发生」，也**不能肯定**箕子王朝鲜「是虚构的」，也同样不能否定钱穆据同一史料建构的先周史。承认这一点，才可能减少因争历史事实而起的族群冲突。
9. **反思性不等于「痛了就要动」。**（前言）作者给反思性下了一个很紧的定义：个人基于对周遭环境的深切认知、对自身处境的真切感知与体认，而产生的情感、意图与行动反应。他补了一句反面的：许多社会运动或革命的参与者，或为实现自身不了解的「理想」而行动、或因自身社会挫折而行动，「最后运动或革命的成功并不能让社会情境更进步、美好」。
10. **他的立场是「体认与体谅」，不是揭发。**（第九章）目标是让现在的人理解「人们所相信的『历史』与社会现实之间的关系」，从而创造出**具反思性认同的中国人**——不必反驳「国族近代建构论」，也不必坚持「中国自古便是多民族国家」，反思性历史知识自能造出具深度认知的国民。

## 13. 论证结构

**前提（作者并没有逐条论证，是整套体系的隐含约定）**：

- 人类的一切表述都是**建构**——「当我们叙述一些事……它都会成为一种建构；仅单单察看、认识这个世界，这不也成为一种建构吗？」（作者引《少年 Pi》里 Pi 对日本海事官员的话，并把它当成自己的立场）
- 社会记忆是人们认知「过去」的唯一材料来源。
- 人们的行为由社会性的「结构」（习性、文类、历史心性）导引，而不是由个体理性逐次计算。

**推论链**：

1. 若表述即建构，则「无偏颇地认识历史事实」不可能 → 那么承诺「客观历史」的史学是空头支票。
2. 但文本总是**在某个社会情境里被生产出来的**，因此文本里必然留下那个情境的痕迹（选材与结构）。
3. 结构性的东西（文类、历史心性）会在**许多各自独立的文本里反复出现**——重复本身就成为可观察的证据。
4. 所以正确的操作是：**从文本的结构反推情境的结构**，并用「移动观察」（同一议题在不同田野点／不同时代的文本比较）来验证。
5. 由此得到的不再是「过去发生了什么」，而是**「在什么样的人类生态下，人们会这样建构他们的『历史』」**——这个命题是谦虚的、也是可检验的。

**隐含假设（书中未充分辩护）**：社会情境与文本结构之间存在**稳定的对应关系**。全书的方法都建立在这一点上；一旦对应关系是松的，反推就会失灵。作者用大量案例（羌、藏、苗、瑶、畲、楚、秦、夫余、朝鲜箕子、北川汉化、湘西少数民族化、晋代会稽）来撑它，但**没有给出「对应不算数」的反例**。

## 14. 未解决之处

**书中明确自认的局限**（这部分要归功于作者诚实）：

- **对「镜下之物」永远只是知其大略。** 凹凸镜的比喻本身就承认：我们可以相当了解凹凸镜（形塑、扭曲人们所信之历史的社会文化因素），但镜下的实物（真正发生的历史）不能确定。
- **全书只处理一类历史**——与国家、民族、文化、乡土、性别、阶级等**社会群体认同**有关的「历史」。作者明说不企图改变伟大历史学者告诉我们的那部历史（重大事件、哲人思想、发明创造）。这是一条自己划出的边界。

**我认为的未解决之处**：

- **「本相」本身怎么被独立地确认？** 全书的方法是「由表相反推本相」，那么用来校对的那个本相从哪来？作者的回答是「移动观察」——用多个田野点之间的**相对**变化来估计。这很聪明，但它只给出**相对**的本相；绝对的本相（那个「真实形貌」）仍然悬在空中。这与作者自己的谦虚立场是一致的，但也就意味着「本相」在实践中常是研究者建构的另一个表相。作者似乎意识到这一点（他反复说「约略」「大略」），但没有正面处理。
- **从「分析」到「行动」的那一步没有桥。** 第九章要造「具反思性认同的中国人」，可第一章的论证只支持「认识」，不支持「改变」。作者在结尾用「揭掉脚底的老茧，让他能感觉脚下所踩的真实世界」来连接——但紧接着自己承认：一个奴隶若安于他的奴隶生活，我们**为何要**让他感到痛苦而反抗？他给的答案是「这经常是掌握权力者的想象，是只见表相而未见本相」。这是一个**立场声明**，不是论证。
- **「人类生态」这一层的经验支撑比「文本」那一层弱得多。** 文本分析部分（第四至第八章前半）有大量一手材料；到「人类生态」的宏观论断（如中东难民潮、ISIS「是我所称欧亚大陆西半部极不均衡的人类生态体系下的表征」）就变成一句话带过。这与全书「用材料说话」的自我要求不太一致。

# 三、评 · 判断

## 15. 评论（按规则 9–15，只挑站得住的）

先说结论：**这是我在这个书单里见过的、方法论密度最高的一本中文著作**，而且它难得地把「我知道的比能说出来的多」用社会学的方式重讲了一遍（下图那条与《意会认知》的对照）。它的四条主要批评，我都能说得具体：

1. **知识错误？没有。** 它引的材料跨度极大（《史记》《华阳国志》《太平寰宇记》、清代方志、1950–60 年代民族调查、1990 年代田野口述、当代电影），我抽查的几处转述与原文方向一致。作者对二手概念（布迪厄、利科、康纳顿）的用法也是在公认的理解范围内。
2. **知识不足？在「社会记忆」的生物学这一侧。** 作者引了托尔文就把话收了，记忆的神经科学证据（遗忘曲线、情境依赖记忆的实验室研究）完全没进来。这对结论影响不大，但它让「为什么社会记忆会变形」这个问题少了一半的解释。
3. **不合逻辑？有一处，是「本相」的循环性**（见上「未解决之处」第一条）。全书方法的核心是反推，而反推需要一个校对点；作者用「移动」来制造这个校对点，这在操作上成立，在逻辑上则默认了「多处相对比较可以逼近绝对」——这是一个未被证明的经验假设。
4. **分析不完整？第七章对「文类」的处理最薄。** 历史心性（第一层）与模式化情节（第三层）都讲得很细，中间那层「文类」主要停在正史与方志两种，而且方志的例子重复出现在第四、七、八三章。这是全书唯一一处可以感到材料在让步于框架。

**它最值钱的地方**，是把「怀疑」做成了一套**可以反复执行的操作**：不问你信不信这个说法，问的是「这个说法是在什么处境下、被谁、按什么格式写出来的」——这个问题对古籍有效，对今天的新闻、公司通报、朋友圈长文同样有效。

## 16. 四个基本问题的回答

**1）整体来说，这本书在谈些什么？**
谈我们如何被「表相」围住，以及史学／人类学可以怎样从表相倒推本相。它是一本**方法之书**，不是历史之书。

**2）作者细部说了什么，怎么说的？**
分四段推进：拆概念（一二章）→ 给框架（三至五章：人类生态、表相本相、认同与记忆）→ 给方法（六至八章：文本与情境、文本结构、三种分析策略）→ 给主张（九章：体认与体谅、反思性中国人认同）。**核心的机关是第七章的三种文本结构**——它是「从文本形状反推社会形状」的具体操作手册，也是全书最不可替代的一章。

**3）这本书说得有道理吗？**
方法那部分（第四至第八章）**有道理，而且可以直接用**：它的每一步都有材料支撑，且作者反复交代限度。最后的主张部分（第九章「反思性中国人认同」）**方向可以同意、论证不够**——它是作者的政治与伦理期待，而第一章已经论证了「我们无法确认历史事实」，这套论证本身并不能推出应该造成什么样的认同。

**4）这本书跟我有什么关系？**
最大的关系是那个**茧**。作者问「为什么赤脚惯了踩在锐石上不知痛」，指的是受过歧视的人对侮辱失去反应、也指我们每个人都住在知识体系搭出来的虚拟世界里。这个问法可以直接搬到今天：**你对一条新闻、一份公司通报、一段「我们一直是这样的」的说法，是「痛」的还是「不痛」的**——不痛，可能只是那层茧已经长起来了。第二层关系是那套操作：看任何一份「文本」时，先问谁写的、为什么现在写、为什么是这个格式。第三层关系是「移动」——要看见自己的凹凸镜，只能换位置；呆在一个点上，只能得到一个偏见。

# 附：与其他书

- **与《意会认知：迈克尔·波兰尼文集》**：最紧的一对。波兰尼说「我们知道的比能说出来的多」，王明珂用**表述性知识／默示性知识**把这句社会学化了：说了什么（可被质疑、可被争论）与没说但已传递的（在意识之外，因而最稳固）要分开看。波兰尼给的是**认知机制**，王明珂给的是这套机制在**社会记忆**里的运行方式。读波兰尼后再读本书第五、六章，会顺很多。
- **与《思考的框架》**：一个给模型，一个拆模型的来源。王明珂要问的不是「用哪个模型」，而是「这个说法本身是按什么格式生成的」——「地图与疆域」这条维度上，他是**拆地图**的那一头。
- **与《思维的囚徒》**：两本都在讲「忍受」是怎么被训练出来的。维克多·弗兰克尔那一路讲意义，王明珂讲**茧**：不是你没有感觉，是那层茧把感觉滤掉了。一个是心理学的路径，一个是社会记忆的路径。
- **与《聪明人的训练》**：那本讲「我做不到」是被许可筛出来的结果；这本讲「我相信的『历史』」是被文类与历史心性筛出来的结果。**同一把刀，一个割个人，一个割群体。**
- **与《纳瓦尔宝典》**：纳瓦尔说「读基础书，别读二手观点」；王明珂会补一句——**你以为的「基础」，也是某个文类里写出来的**。
