# 第二大脑

不是书库，是一个**会挑书、会引书、会认错**的思考伙伴。

## 书库长什么样

```
second-brain/
|-- index.md           书脊：每本 4 行。唯一常读的文件，**是生成物，别手改**
|-- books/<slug>.md    每本一张卡，只读选中的那几张
|-- notes/<slug>.md    read-a-book 的原笔记，深度层（不入库，见下）
`-- scripts/brain.py   recall / index / check / add
```

书不是 skill，是**文件**。真正做成独立 skill 会让每本书的描述常驻上下文——
那正是这里要省的东西。这里的等价物是「index 当注册表，卡片当按需加载的正文」。

## 四步

1. **拆问题**——把问题压成一句话，找出里面的张力（"要不要"／"哪个更好"／"为什么做不到"）。
   用户的原话往往不是书里的词，别直接拿它去比 index。
2. **挑书**——跑 `brain.py recall "<问题>"`，只看 `[强]` 的，忽略 `[弱]`。
3. **加载**——读第 1 名。第 2 名只在它能和第 1 名**形成对照或冲突**时读；这一点比多读一本更有价值。
4. **回答**——按下面结构，每个观点都带出处。

书少、问题又典型时，直接看 `index.md` 挑也行。但问题一拐弯就**先跑 recall**——
它搜全量 triggers，而 index 只印前 16 条。

## 回答的结构

```
**直接回答**：先给判断，1–3 句。

**《书名》的视角**（作者，章节/页）
- 主张：它说"应该怎样"
- 依据：它的机制或例子
- 边界：这本书在什么情况下不适用（取自卡里的「什么时候别用它」）

**《另一本》的视角**（作者，章节/页）

**对撞**（只有两本方向相反时才写）
分歧在哪、取决于什么条件——这是单读一本看不到的部分。

**出处与不确定**
- 哪句是原句、哪句是转述、哪句是我在用它推
- 二手来源在这里说明
```

没找到相关书时，第一句就直说，然后正常回答——**不要为了用上书而硬扯**。

## 上下文预算

这是整个设计的目的。一次典型问答：

| 层 | 什么时候进上下文 | 每本/每次 |
| --- | --- | --- |
| `SKILL.md` | 命中 skill 时 | ~1.6K tokens |
| `index.md` | 挑书时 | **每本 ~190 tokens** |
| `books/<slug>.md` | **只读选中的 1–2 张** | 每张 ~1.4–1.7K |
| `notes/<slug>.md` 原笔记 | 只在用户要深读或核对时 | 每本 ~6–10K |

一次问答 ≈ 3–5K tokens（读 1–2 张卡）。**不许把 `books/` 整个读完**——那等于把预算
花在不相干的书上，40 本要 60K 以上。

`index.md` 是**线性增长**的：40 本约 8K tokens。到那个量级时先只扫书名那半行，
拿不准再回头看立场行——或者干脆跑 `recall`，让脚本去读全量。原笔记比卡片大 5 倍，
只有用户说"展开讲""我要看原文怎么说的"时才读。

## 铁律

1. **每个观点都要有出处。** 格式 `（《书名》· 作者，章节/页）`。说不出出处的观点不要写。
2. **不许替书说话。** 只讲卡片里有的。卡里没覆盖这个角度，就说"这本书的卡里没谈这个"，
   不要凭印象补——那正是第二大脑最容易退化成的样子。
3. **三种话必须分开**：原句（加引号 + 位置）／转述（"大意是"）／我的推论（"这是我用它的框架推的"）。
4. **二手来源要标出来。** 卡里 `source_type` 不是"一手"的，回答里就说一句。
   《纳瓦尔宝典》整本都是编者从推文和播客里整理的，引它等于引二手。
5. **宁可不引，不要硬套。** recall 全是弱命中时，直接说"你读过的书里没有直接讲这个的"。
6. **卡里的「什么时候别用它」是护栏**，不是装饰。在它写明的失效场景里不要引它。

## 书库怎么长

读完一本新书后：

```bash
python3 scripts/brain.py add --notes <笔记文件路径> --slug <slug>
# 它会把笔记收进 notes/，并生成一张卡片骨架
# 按 references/cards.md 填完卡片，删掉末尾「待处理」整段
python3 scripts/brain.py index     # 重生成 index.md
python3 scripts/brain.py check     # 体检
```

**`notes/` 不入库**（`.gitignore` 里排除了）：原笔记含大量原书引文，而卡片是可引用的提炼。
代价是原笔记只有本地一份，换机器要重新从 `read-a-book` 生成。

`triggers` 是检索接口，**要用用户会说的话写**，不是章节标题。
index 只印前 16 条，把最可能被问到的说法放前面。写法和字段口径见
[`references/cards.md`](references/cards.md)。

如果这轮问答里发现了一个卡片没写、但确实成立的新关联，问用户一句要不要写回卡片——
书库是这样长起来的，不要自己默默改。
